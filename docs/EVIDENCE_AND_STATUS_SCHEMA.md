# EVIDENCE_AND_STATUS_SCHEMA.md — 证据与状态统一 Schema

> 版本：v1（2026-10-09 审计批次）。本文件是 CHARCOAL HUB 五站证据等级与验证状态的唯一权威定义。

## 1. 六级证据维度（A–F）

| 级别 | 名称 | 定义 | 典型证据 |
|---|---|---|---|
| A | 未核验资料 | 信息存在但来源未核验，仅作线索 | 网络公开线索、目录信息、传闻 |
| B | 供应商自述 | 供应商单方提供，平台未独立验证 | 供应商填写的规格、资质描述、自述产能 |
| C | 已核验文件 | 平台已收到并核对过文件本身 | 营业执照复印件、质量体系文件扫描件 |
| D | 已核验企业身份 | 企业主体存在性经独立渠道确认 | 工商注册登记查询、官方数据库核对 |
| E | 已核验产品或工厂能力 | 产品或生产能力经平台实地/实质核验 | 验厂记录、样品实测、产能现场核对 |
| F | 有可追溯报告的第三方检测 | 独立第三方检测且报告可追溯 | 带编号的实验室报告（可向实验室核实） |

## 2. 与现有四级 verification 状态映射

### data.guotan（data 站）

| 现有状态 | 六级映射 | 说明 |
|---|---|---|
| unverified | A | 未核验 |
| supplier-declared | B | 供应商自述 |
| document-verified | C | 已核验文件 |
| fbo-verified | D | 已核验企业身份 |
| third-party-tested | F* | 仅当报告可追溯才为 F，否则降为 B/C |

### manufacturer.guotan（manufacturer 站）

| 现有状态 | 六级映射 | 说明 |

| Unverified | A | 未核验 |
| Supplier Reported | B | 供应商自述 |
| Verified | C–D 区间 | 按档案实际证据定位：只有文件为 C，有独立身份确认才为 D |

| 现有状态 | 六级映射 |

## 3. 边界规则（必须写入展示层与 schema 注释）

1. **身份核验 ≠ 质量证明**：企业真实存在（D）不代表其产品合格。质量声明必须有 E/F 证据。
2. **营业资料 ≠ 工厂能力**：有营业执照（C/D）不代表有工厂、有产能（E）。
3. **供应商报告 ≠ 平台独立验证**：供应商转发的检测报告未核实前只是 B（供应商自述），报告编号可追溯核实后才可标 F。
4. **无证据 → 降级声明**：任何无法定位到 A–F 某一级的声明，一律标"待核验"，不得补写推测事实。
5. **展示规则**：页面徽章显示当前级别及证据类型，不显示更高目标级别，避免拔高。
